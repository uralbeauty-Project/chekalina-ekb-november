САЙТ СВЕТЛАНЫ ЧЕКАЛИНОЙ — ДЛЯ GITHUB PAGES

1. Распакуйте архив.
2. Откройте github.com/uralbeauty-Project/chekalina-ekb-november
3. Нажмите Add file → Upload files.
4. Откройте распакованную папку и перетащите в GitHub все файлы и папку assets (не сам ZIP).
5. Внизу нажмите Commit changes.
6. GitHub Pages: Settings → Pages → Build and deployment → Source = GitHub Actions.

Адрес сайта после публикации: https://uralbeauty-project.github.io/chekalina-ekb-november/

Примечание: шрифты заменены системными для переноса без распространения файлов шрифтов.
